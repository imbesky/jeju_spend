# 제주도 카드 사용 분석 미니 프로젝트

## 1. 프로젝트 개요

제주도 내 카드 사용 데이터를 기반으로 행정구역, 관광 업종, 국적별 차이 등 관광객들의 소비 패턴을 분석해 관광 소비 활성화 전략 수립

- 기간: 2025.6.20 - 2025.6.23(EDA, 패턴 분석), 2025.12.20 - 2025.12.21(clustering, 전략 도출)
- 목표: 각 행정구역별, 관광 업종별 관광객 집단 특성 맞춤형 전략 수립
- 프로젝트 인원: 1명(개인 프로젝트)
- 사용 tool: pandas, matplotlib, seaborn, scikitlearn

### 프로젝트 배경

1. 경기의 둔화
최근 다양한 이유로 경기가 둔화됨 (2024년 12월 기준)
- 자영업자 563만 6천 여명, 소비 19.7%가량 감소
- 평균소비성향* 69.4%로 전년 동기 대비 하락; 7분기만에 70% 이하

2. 관광업의 기회
대한민국은 GDP 대비 관광 산업 규모가 작은 나라
- OECD 주요국 평균 10.4%
- 2022년 2.8%, 51개국 중 최하위

## 2. 데이터

- 보유 기관: 제주특별자치도
- 데이터: 2014~2016년도 제주 지역 내 내국인, 중국인 관광업종 BC카드 결제 데이터 
- 비고: 2014.09 - 2016.08 자료로 2025년 현재 시점과는 약간의 차이가 있을 수 있음

### 주요 변수

- 지역 구분: 시, 읍/면/동, 도심/도심외
- 업종: 숙박, 식음료, 쇼핑 등
- 결제 정보: 결제 금액, 이용 건수
- 거주지: 제주도, 제주 외 한국, 중국

## 4. 결론

### 관광객 집단별 특성

1. 내국인 관광객
- 소비 분포: 도심부터 유명한 관광지가 위치한 지역, sns에서 유명한 동네 등 제주 전역에서 소비
- 소비 성향: 쇼핑, 식음료의 비중이 높음
- 시사점: 재방문이 쉬운 집단으로 비교적 덜 유명한 명소로의 유입을 유도하기 유리

2. 중국인 관광객
- 소비 분포: 연동, 노형동 등 도심과 주요 관광지에 소비가 집중되어 있음
- 소비 성향: 쇼핑과 숙박의 비중이 매우 크며 객단가가 월등히 높음
- 시사점: 쇼핑 업종과 도시 쇼핑 상권 강화에 집중하는 것이 효율적

### 행정구역별 특성

K-Means clustering을 통해 4 가지 유형으로 분류
각 집단은 행정구역과 쇼핑 업종을 기준으로 나눔

1. 고성장 집단
- 결제 규모와 건수 급성장
- 특정 지역의 쇼핑 업종 한 건이므로 outlier로 취급

2. 성장 집단
- 결제 규모와 건수가 성장
- 잠재력 있는 지역과 업종으로 관광객들의 관심이 높아진 상태

3. 유지 집단
- 결제 규모와 건수가 거의 성장하지 않고 유지된 집단
- 성장폭을 높이기 위한 방안 마련 필요

4. 쇠퇴 집단
- 결제 규모와 건수가 감소하거나 이전과 거의 유사하게 유지된 집단
- 관광객들의 인기가 줄어든 원인을 분석하고 대책 마련 필요

### 관광업종별 특성

- 쇼핑&소매: 관광객 집단을 막론하고 1순위 소비 업종으로 객단가가 가장 높게 형성
- 식음료: 내국인 관광객의 결제 빈도가 가장 높은 업종으로 맛집 소비 위주일 것으로 예상됨
- 숙박: 내국인의 결제 규모가 중국인의 결제 규모에 비해 낮음
- 문화/레저: 비중이 낮음

### 관광 소비 활성화 전략

1. 객단가 상승 프로젝트
- 내국인의 낮은 객단가 극복
- 숙박이나 항공권과 같은 필수 서비스와 문화/레저 상품을 결합
- 재방문자 대상 할인, 특별 여행 코스 등의 프로모션

2. 제주 식도락 여행
- 식음료 업종에서 많이 소비하는 내국인 대상
- 유명 음식점 및 인근 맛집, 교통편 정보 제공
- 상대적으로 소비 규모가 작은 업종 이용시 식음료 바우처 제공

3. 쇼핑 VIP 마케팅
- 쇼핑 업종에서 많이 소비하는 중국인 대상
- 중국인 관광객이 많이 찾는 방문지에 안내시설, 쇼핑 상권 유치
- 픽업 서비스, 전용 라운지 등 편의시설 제공
